# 接入 Audio2Face 前版本保存

保存范围：当前电脑侧 RAI、duplex、动作运行时、舞蹈、已验证播放器与文档；机器人侧保存当前实际部署目录和控制工作区源码。备份不停止服务，不触发动作。

电脑归档位于 `deployment/checkpoints/pre-audio2face-<时间>/`。源码包排除虚拟环境、构建产物、日志、config.toml 和密钥文件；config.toml 单独存入本机 private-config.tar.gz，不用于分享。SHA256SUMS 用于校验。

机器人端执行：

```bash
bash /home/cat/rai/save_robot_checkpoint.sh
```

结果位于 `/home/cat/rai/checkpoints/pre-audio2face-<时间>/`。deployed-code.tar.gz 保存代码与非密钥配置；private-config.tar.gz 单独保存三个环境令牌文件和 RAI/duplex 的 config.toml。私密包仅留在设备，不上传或分享。

归档保留舞蹈与姿势数据、motor.yaml、动作/舞蹈清单、交互配置、bridge 源码配置；不保存编译后的 install/build。新机器恢复需重建 ROS 工作区及环境。platform.txt、ai-requirements.txt 用于核对部署环境。

恢复前先停止相关服务，并备份当前目录；先解压到新的恢复目录检查内容，不直接覆盖运行部署。归档是部署文件快照，不包含正在运行的进程内存或对话会话。
