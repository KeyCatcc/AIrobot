# 舞蹈语音集成

当前采用 RAI single 结构化决策：`behavior,target,source`。behavior 为 none、gesture、dance、cancel_dance。舞蹈只接受 user_request 来源。泛指“给我跳个舞”“来段表演”输出 dance/random，由程序从 enabled=true 且 rai_exposed=true 的舞蹈中随机选择。指定名称按名称和 aliases 选择，不存在则不替换。无运行舞蹈时取消决策归为 none。

bishangguan 默认速度 0.5，无音乐，单次播放，结束用 6 秒回零。人工客户端可用 `--speed 0.7` 覆盖本次速度，范围 0.05–1.0。语音暂不调速。

部署时将以下文件同步到机器人对应目录；覆盖机器人舞蹈清单前先保留原件，避免丢失机器人上另行登记的舞蹈：

- rai-main/examples/agents/gesture_decision.py
- rai-main/examples/agents/remote_gesture_tool.py
- rai-main/examples/agents/duplex_wave_server.py
- robot-action-runtime/scripts/action_http_server.py
- robot-action-runtime/scripts/dance_catalog.py
- robot-action-runtime/scripts/dance_http_client.py
- robot-action-runtime/configs/dances/dance_catalog.json
- python3.7_duplex_demo/python3.7_duplex_demo/robot_dialogue_instructions.txt

机器人 RAI 与 duplex 仍位于 `/home/cat/rai/releases/20261110-ai/` 内。保持 RAI_DECISION_MODE=single。同步后按全量手册重启动作服务、RAI 和 duplex，人脸跟随可保持运行。

验收语句：

1. 给我跳个舞吧。预期 bishangguan，speed=0.5，头部让权。
2. 停止跳舞。预期 cancel_requested，回零后 cancelled_returned_home，恢复头部发布器。
3. 来段表演。预期白名单随机舞蹈。
4. 跳一段碧山关。预期 bishangguan。
5. 解释一下跳舞是什么意思。预期不播放舞蹈。
6. 不要跳舞，向我挥手。预期仅挥手。
7. 跳一个目录中不存在的舞蹈。预期不替换为 bishangguan。

人工调速：

```bash
source /home/cat/rai/.robot_action.env
cd /home/cat/rai/robot-action-runtime
python3 scripts/dance_http_client.py --dance bishangguan --speed 0.7
python3 scripts/dance_http_client.py --cancel
python3 scripts/dance_http_client.py --status
```

RAI 日志 `[RAI behavior]` 记录模型决策；Action Service 的 `/execution` 记录最终随机选中的舞蹈和实际速度。duplex 的口头应答不是执行完成确认。
